## 🧠 Методологія ML

### Підготовка даних

CSV містить 9 576 рядків. Ми застосовуємо такі фільтри (узгоджені з валідацією на бекенді):

| Поле | Фільтр | Чому |
|---|---|---|
| `price` | `500 < price < 150 000` | відсіюємо явні «копійки» та виборки |
| `year` | `1990 < year ≤ 2025` | прибираємо застарілі та помилкові записи |
| `engV` | `0.1 ≤ engV ≤ 10` | реальні об'єми двигунів |
| `mileage` | `0 ≤ mileage ≤ 999` (тис. км) | відсіюємо помилки введення |
| `car`, `model` | `dropna` | без бренду/моделі прогноз неможливий |

### Ознаки

- **Категоріальні** (OneHotEncoder, `handle_unknown='ignore'`): `car`, `model`, `body`, `engType`, `drive`
- **Числові** (median imputation): `mileage`, `engV`, `year`

### Порівняння алгоритмів (5-fold CV)

Тренувальна вибірка ділиться на 5 фолдів. Перемагає той, у кого найменша середня абсолютна помилка (**MAE**) у доларах:

```
  LinearRegression    MAE = $5 ???    R² = 0.6??
  GradientBoosting    MAE = $2 ???    R² = 0.8??
  RandomForest        MAE = $2 ???    R² = 0.8??   ← переможець
```

(Точні значення з'являться після запуску `train_model.py` — дивись `model_metrics.json`.)

### Метрики на hold-out (20 % від датасету)

- **MAE** — у доларах: показує середню абсолютну помилку
- **MAPE** — відсоткова: інтерпретовніша для широкого діапазону цін
- **RMSE** — штрафує великі помилки сильніше за MAE
- **R²** — пояснена дисперсія

### Довірчий інтервал прогнозу

Замість одного числа віддаємо інтервал. Використовуємо варіансу між окремими деревами `RandomForestRegressor`:

```python
tree_preds = [tree.predict(x)[0] for tree in regressor.estimators_]
mean, std = tree_preds.mean(), tree_preds.std()
interval_95 = (mean - 1.96 * std, mean + 1.96 * std)
```

Це **епістемічна невпевненість** — наскільки ансамбль «не знає» цю точку. Для авто з малою кількістю аналогів у датасеті інтервал буде ширшим.

### Оцінка надійності

Окремий сигнал — скільки записів схожих на введене авто є в датасеті:
- `≥ 20 записів` → high
- `5–19` → medium
- `< 5` → low + попередження «екстраполяція»

### Важливість ознак

З `RandomForest.feature_importances_`. Категоріальні (після OneHot) розгортаються назад: внески всіх категорій одного поля підсумовуються.

## 📡 API-довідник

Базова URL: `http://127.0.0.1:8000`

| Метод | Шлях | Опис |
|---|---|---|
| GET  | `/`                    | health check + версія |
| GET  | `/options`             | списки марок/моделей, специфікації за моделлю, обмеження |
| GET  | `/metrics`             | точність моделі (MAE/MAPE/R²) + результати CV |
| GET  | `/feature-importance`  | вклад кожної ознаки |
| POST | `/predict`             | прогноз ціни з `{low, mean, high}` інтервалом, `confidence`, попередженням |
| POST | `/similar-cars`        | топ-N найближчих авто з датасету |
| GET  | `/stats`               | агреговані дані для EDA-вкладки |

## ⚠️ Обмеження та допущення

1. **Датасет статичний.** Ціни прив'язані до моменту збору даних. Для прод-апки треба регулярне дозбирання.
2. **Курси валют (UAH/EUR) — статичні константи** на фронті. Для реального проєкту — інтегрувати API НБУ.
3. **Модель не знає про регіон, стан кузова, історію ДТП, кастом-комплектації.** Це фундаментальне обмеження датасету.
4. **Прогнози для майбутніх років (2026+) — екстраполяція.** RandomForest не виходить за межі тренувальних значень, тому такі оцінки наближені до останніх відомих років.
5. **CORS** обмежено локальними портами Vite/CRA. Для продакшену — оновити список у `main.py`.
6. **Інтервал — не баєсівський.** Це епістемічна невпевненість ансамблю, а не справжній інтервал передбачення з шумом.
